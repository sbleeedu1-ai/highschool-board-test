# 04: 관리자 로그인·로그아웃

**What to build:** 관리자가 숨겨진 로그인 화면에서 아이디·비밀번호로 로그인한다. 로그인한 동안에는 로그아웃 버튼이 보이고, 직접 로그아웃할 수 있다. 로그인은 30분 동안 아무것도 하지 않으면 만료된다. 로그인하지 않고 관리자 화면에 들어오면 로그인 화면으로 보낸다. 관리자 계정은 환경변수로 받고, 비밀번호 해시는 로컬 명령으로 만든다(ADR-0002).

**Blocked by:** 01 (걷는 뼈대)

**Status:** ready-for-agent

명세 사용자 이야기: 24-33, 47(로그인 화면 이동 부분), 53(401 처리 부분), 58-59, 66, 68

- [x] 관리자 아이디·비밀번호 해시를 환경변수로 받는다(DB 사용자 표 없음). 로컬은 git에서 제외된 파일에서 읽는다
- [x] 로컬 전용 Gradle 명령이 비밀번호를 입력받아 해시만 출력한다(원문은 저장·출력하지 않음)
- [x] `POST /api/auth/login`, `POST /api/auth/logout`, `GET /api/auth/me`
- [x] 메모리 세션. 쿠키는 HttpOnly·Secure(`local`에서는 Secure 끔), 30분 무활동 시 만료
- [x] CSRF: Spring Security `csrf.spa()`. 프론트가 토큰을 붙여 보낸다
- [x] 로그인 실패 문구는 "아이디 또는 비밀번호가 올바르지 않습니다" 하나뿐이다
- [x] 로그인 화면은 `/admin/login`이고, 방문자 화면에는 링크가 없다
- [x] 로그인 상태에서만 로그아웃 버튼이 보인다
- [x] 로그인하지 않고 관리자 화면(`/admin/notices/*`)에 들어오면 로그인 화면으로 이동한다
- [x] API가 401을 주면 로그인 화면으로 이동하고 작성 중 내용을 잃을 수 있다고 안내한다. 403(CSRF)이면 "다시 시도해 주세요"를 보여 준다 — 05에서 브라우저로 확인(등록 중 로그아웃 → 만료 안내, CSRF 쿠키를 지우고 등록 → "다시 시도해 주세요")
- [x] HTTP API 테스트: 로그인 성공·실패, 로그아웃, `me`, 세션 쿠키 속성, CSRF 토큰 없는 변경 요청 403
