# 05: 공지 등록

**What to build:** 로그인한 관리자가 공지 목록의 [새 공지]를 눌러 제목과 본문을 입력하고 등록하면, 새 공지의 상세로 이동한다. 입력하는 동안 글자 수를 보고, 제한을 어기면 칸 아래에서 안내를 받는다. 최종 판정은 백엔드가 한다.

**Blocked by:** 03 (공지 상세 보기), 04 (관리자 로그인·로그아웃)

**Status:** ready-for-agent

명세 사용자 이야기: 39-47

- [x] `POST /api/notices`(관리자만): 앞뒤 공백을 지운 뒤 제목 1-100자, 본문 1-5,000자. 공백만 있으면 거부. 생성된 공지를 돌려준다
- [x] 입력 오류는 400과 `fieldErrors`(칸별 안내)
- [x] 로그인했을 때만 공지 목록에 [새 공지] 버튼이 보인다
- [x] 등록 화면 `/admin/notices/new`: 글자 수 표시(`37/100`), 입력 중 안내, 서버가 준 `fieldErrors`를 칸 아래에 표시
- [x] 등록 후 새 공지의 상세로 이동한다
- [x] HTTP API 테스트: 등록 성공, 미로그인 401, CSRF 없음 403, 경계값(제목 100/101자, 본문 5,000/5,001자), 공백만, 앞뒤 공백 제거, 작성일시가 시계 값인지
