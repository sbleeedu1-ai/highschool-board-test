# 07: 공지 삭제

**What to build:** 로그인한 관리자가 공지 상세의 [삭제]를 누르면 "정말 삭제할까요?" 확인 창이 뜨고, 확인하면 공지가 완전히 삭제되어 공지 목록으로 돌아간다. 이미 삭제된 공지를 지우려 하면 안내를 받는다.

**Blocked by:** 05 (공지 등록)

**Status:** ready-for-agent

명세 사용자 이야기: 54-57

- [ ] `DELETE /api/notices/{id}`(관리자만): 완전 삭제. 없으면 404
- [ ] 로그인했을 때만 공지 상세에 [삭제] 버튼이 보인다
- [ ] 확인 창에서 취소하면 아무 일도 일어나지 않는다
- [ ] 삭제 후 공지 목록으로 이동한다
- [ ] HTTP API 테스트: 삭제 성공 후 상세 404, 미로그인 401, CSRF 없음 403, 없는 공지 404
