# 10: 운영 E2E 1회와 점검표

**What to build:** 첫 배포 직후 운영 주소에서 브라우저 자동 테스트가 방문자·관리자 전체 흐름을 한 번 통과하고, 사람이 점검표로 마지막 확인을 한다. 이 티켓이 끝나면 구현 완료 기준을 모두 충족한다.

**Blocked by:** 09 (배포)

**Status:** ready-for-agent

명세 사용자 이야기: 76-77 / 테스트 결정 "시스템", "구현 완료 기준"

- [ ] Playwright 테스트(프론트 폴더): 목록·상세 → 로그인 → 등록 → 수정 → 삭제 → 로그아웃
- [ ] 테스트 공지 제목은 `[E2E 테스트]`로 시작하고, 테스트가 중간에 실패해도 마지막에 반드시 삭제를 시도한다
- [ ] 로그인 잠금은 E2E에 넣지 않는다(운영에서 테스트하는 IP가 잠기기 때문)
- [ ] 운영 주소와 관리자 계정은 실행할 때 환경변수로 받고 저장소에 남기지 않는다(CI에서 상시 실행하지 않음)
- [ ] 운영 주소로 1회 실행해 통과한 결과를 기록한다
- [ ] 사람용 점검표: Safari·아이폰에서 로그인 유지, 휴대폰 화면, 링크가 새 탭으로 열리는지, 30분 무활동 시 만료 등 자동 테스트로 확인하지 않은 항목
- [ ] 점검표 확인을 마치면 명세의 Status를 완료로 바꾼다
