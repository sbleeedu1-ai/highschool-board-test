# 비밀 헤더로 방문자 IP를 신뢰하고, 로그인 잠금은 IP별로 한다

관리자 계정 단위로 "5회 실패 시 10분 잠금"을 하면, 누구나 틀린 비밀번호를 5번 넣어 진짜 관리자를 계속 막을 수 있다. 그런데 요청이 Pages Functions를 거쳐 오므로 백엔드는 방문자의 실제 IP를 알 수 없다. 그래서 Functions가 `X-Client-IP`(방문자 IP)와 `X-Proxy-Secret`(Functions와 백엔드만 아는 비밀값)을 붙이고, 백엔드는 비밀값이 맞을 때만 그 IP를 믿어 **IP별로 5회 연속 실패 시 10분 잠금**한다. 비밀값이 없는 요청은 `/actuator/health`(Railway 상태 확인)를 빼고 모두 거절하므로 Railway 주소로 직접 들어오는 우회 접근도 막힌다.

## Consequences

- 비밀값은 Railway와 Cloudflare Pages 양쪽 환경변수에 같은 값으로 넣어야 하며, 바꿀 때도 양쪽을 함께 바꾼다.
- 잠금 기록은 서버 메모리에만 있어 재배포하면 초기화된다.
- `local` 프로필에서는 비밀 헤더 검사를 끈다.
