# 작업 인계 (HANDOFF) 규칙

PC(집·강의실)와 에이전트(Claude·Codex)를 오가므로, 채팅 기억 대신 저장소 루트의 `HANDOFF.md`로 작업을 잇는다.
`handoff` 스킬은 OS 임시 폴더에 저장하라고 하지만, 임시 폴더는 다른 PC에서 볼 수 없으므로 이 저장소에서는 루트의 `HANDOFF.md`에 저장한다. 작성 원칙(추천 스킬, 링크로 대신하기, 비밀값 제거)은 스킬을 따른다.

## 어디에 있나

- `HANDOFF.md`는 **작업 브랜치**에서 고치고 함께 커밋한다. PR이 병합되면 `main`으로 간다.
- `main`의 `HANDOFF.md`는 오래된 것일 수 있다.

## 시작할 때

1. `git fetch`
2. `gh pr list`로 열린 PR과 최근 작업 브랜치를 확인한다.
3. 그 브랜치로 이동해 `HANDOFF.md`를 먼저 읽는다.

## 커밋할 때마다

- `HANDOFF.md`를 최신 상태로 **다시 쓴다**(덧붙여 쌓지 않는다. 지난 내용은 git 이력에 있다).
- 작업 내용과 함께 커밋하고 **작업 브랜치에 push**한다(사용자가 이 저장소의 작업 브랜치 push는 미리 허락함).
- PR 생성, `main` 병합, `main` push는 매번 사용자 확인을 받는다.

## 형식

```markdown
# HANDOFF

마지막 갱신: 2026-10-16 · Claude · 강의실 PC

## 다음 할 일
(다음 세션이 집중할 일 하나를 맨 위에)

## 현재 상태
(어디까지 됐는지, 작업 브랜치, PR 링크)

## 막힌 점 / 확인이 필요한 결정

## 마지막 검증
(마지막으로 돌린 명령과 결과: 통과/실패)

## 추천 스킬
- `/스킬이름`: 무엇을 할지 한 줄 (Codex는 이 한 줄을 그대로 따른다)

## 참고 문서
(경로·링크만)
```

## 쓰지 않을 것

- 명세(`.scratch/`), ADR(`docs/adr/`), 용어집(`CONTEXT.md`), 커밋·PR에 이미 있는 내용. 링크로 대신한다.
- API 키, 비밀번호, 비밀번호 해시, 프록시 비밀값, 개인정보.
